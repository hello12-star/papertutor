# PaperTutor 成本估算（3 篇示例论文）

> 价格抓取日期：2026-11-17。只查公开定价，未调用任何付费 API。
> 币种：人民币（CNY）。使用官方页面展示的原价，不含控制台活动优惠、Batch 折扣或上下文缓存折扣。
> 本文是估算，不是账单；实际费用以阿里云账单为准。

## 1. 结论摘要

当前仓库里的 3 篇示例（Attention / ResNet / LoRA）是**预生成 JSON**。评委打开示例不会调用 DocMind 或 LLM，**运行时成本为 0**。下面的数字是“重新生成这 3 篇”的成本。

- 3 篇合计 **46 页**：Attention 15 页、ResNet 12 页、LoRA 19 页。
- DocMind：基础链路 **0.02 元/页**，增强链路 **0.04 元/页**；图文文档每月 **3,000 页**免费额度。
- LLM（非思考模式）：
  - `qwen-plus` 0–128K：输入 **0.8 元/百万 token**，输出 **2.0 元/百万 token**。
  - `qwen-max`：输入 **2.4 元/百万 token**，输出 **9.6 元/百万 token**。
- 一次三篇完整分析（DocMind + LLM）估算：
  - `qwen-plus` + DocMind 基础/增强：**约 1.02–1.99 元**。
  - `qwen-max` + DocMind 基础/增强：**约 1.29–2.42 元**。
- 每日 1 元预算（DocMind 免费额度用尽后）：
  - 三篇一组 1.02–1.99 元（`qwen-plus`）或 1.29–2.42 元（`qwen-max`），**1 元/天不足一组**，建议按单篇调用。
  - 单篇粗算：`qwen-plus` 约 0.27–0.82 元/篇（1 元约 1–3 篇），`qwen-max` 约 0.35–0.97 元/篇（1 元约 1–2 篇）。
- 若 DocMind 仍在每月 3,000 页免费额度内：只计 LLM，三篇 0.10–0.15 元（`qwen-plus`）或 0.37–0.58 元（`qwen-max`），约 **6–10 组/天**（`qwen-plus`）或 **1–2 组/天**（`qwen-max`）；但每月免费页数只够约 **65 组**。

> “1 元/天”是 PaperTutor 应用层的预算上限，不是阿里云的账单上限。DocMind 按自然月后付费出账，LLM 按调用计费。

## 3. 页数与 token 假设

### 3.1 页数

页数来自 `public/demo/*.json` 的 `doc.pages`：

| 论文 | 页数 |
|---|---:|
| Attention Is All You Need | 15 |
| Deep Residual Learning for Image Recognition | 12 |
| LoRA: Low-Rank Adaptation of Large Language Models | 19 |
| 合计 | 46 |

### 3.2 token 假设

项目样例（13 页）解析出 50,734 字符，约 **3,900 字符/页**（见 `docs/handoff-M1-D1-2026-11-17.md`）。英文按约 4 字符/token，折算约 **975 token/页**。考虑公式、表格和版式差异，本文取 **900–1,100 token/页** 作为区间。

当前分析链路每条论文会调用两次 LLM：

1. 速览卡 `generateQuickview`
2. 论证骨架 `generateSkeleton`

两次都会发送论文 Markdown，因此输入 token 按“页数 × 单页 token × 2”计算。`lib/analysis.ts` 的 Markdown 上限是 90,000 字符；三篇论文按上述假设都低于上限（LoRA 最高约 74,100 字符）。

输出 token 取代码中的上限作为上界：

- 速览卡 `QUICKVIEW_MAX_TOKENS = 3,600`
- 论证骨架 `SKELETON_MAX_TOKENS = 8,000`
- 低值假设：速览 1,800 + 骨架 4,000 = **5,800**
- 高值假设：速览 3,600 + 骨架 8,000 = **11,600**

| 论文 | 页数 | 单次输入低/高 | 两次输入低/高 | 输出低/高 |
|---|---:|---:|---:|---:|
| Attention | 15 | 13,500 / 16,500 | 27,000 / 33,000 | 5,800 / 11,600 |
| ResNet | 12 | 10,800 / 13,200 | 21,600 / 26,400 | 5,800 / 11,600 |
| LoRA | 19 | 17,100 / 20,900 | 34,200 / 41,800 | 5,800 / 11,600 |
| 三篇合计 | 46 | — | 82,800 / 101,200 | 17,400 / 34,800 |

不计入本文估算的项目：

- 帮助系统的预生成/现场生成（按控件计，不走每篇论文两次分析；且任务书规划用 `qwen-turbo`）。
- 重试、重新生成、失败重试产生的额外调用。
- 上下文缓存、Batch 折扣、免费 token 额度。
- DocMind 的图片 OCR、音视频等非图文文档。

### 3.3 计算公式

```text
DocMind 成本 = 页数 × 单价（0.02 或 0.04）
LLM 成本 = 输入 token / 1,000,000 × 输入单价
         + 输出 token / 1,000,000 × 输出单价
单篇总成本 = DocMind 成本 + 速览 LLM 成本 + 骨架 LLM 成本
```

## 5. 每日 1 元预算能支撑多少次

### 5.1 DocMind 免费额度用尽后（计入 0.02–0.04 元/页）

按“一次完整分析三篇”计：

| 模型 | 单组成本 | 1 元/天 |
|---|---:|---|
| `qwen-plus` | 1.02–1.99 元 | **不足一组** |
| `qwen-max` | 1.29–2.42 元 | **不足一组** |

1 元/天不足一组，建议按单篇调用。单篇粗算：`qwen-plus` 约 0.27–0.82 元/篇（1 元约 1–3 篇），`qwen-max` 约 0.35–0.97 元/篇（1 元约 1–2 篇，随论文页数变化）。

### 5.2 DocMind 仍在每月 3,000 页免费额度内

只计 LLM：

| 模型 | 三篇 LLM 成本 | 1 元/天理论组数 |
|---|---:|---:|
| `qwen-plus` | 0.10–0.15 元 | **6–10 组/天** |
| `qwen-max` | 0.37–0.58 元 | **1–2 组/天** |

但免费额度是**每月 3,000 页**，三篇 46 页，最多约 **65 组/月**（65 × 46 = 2,990 页；第 66 组会超出）。因此免费额度内，月度页数上限通常先于每日 1 元上限生效。

## 6. 敏感性

- **页数/token 密度**：公式、表格、参考文献多的论文会拉高 token/页；扫描件 OCR 也可能增加解析成本。
- **输出长度**：模型实际输出可能低于上限；本文高值按代码上限计，属于保守估计。
- **重试/重新生成**：每次重试或重新生成都会重复 LLM 调用；DocMind 解析缓存命中时可避免重复解析。
- **模型选择**：当前代码对速览和骨架使用同一个 `settings.model`。若未来拆成 `qwen-plus`（速览）+ `qwen-max`（骨架），成本会落在两个表之间。
- **qwen-plus 思考模式**：若打开思考模式，0–128K 输出单价从 2.0 提高到 8.0 元/百万 token；当前代码显式关闭。
- **DocMind 链路**：增强链路 0.04 元/页是基础链路的两倍；实际接入时需确认使用哪条链路。
- **价格变化**：本文抓取于 2026-11-17；官方页面可能调整，比赛前应复核。
- **预算估算成本**：默认 `ESTIMATED_ANALYSIS_COST_CNY=0.05` 只估算 LLM；DocMind 免费额度用尽后应把它调到约 0.6，否则 1 元/天会放过约 20 次调用，高于真实花费。
- **预算实现边界**：`functions/budget.ts` 目前是进程内 mock，冷启动重置；上线前必须改为持久化计数。本文的“1 元/天”是产品目标，不是已上线的计费器。
