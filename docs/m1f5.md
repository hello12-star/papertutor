### 零付费的复测方式

Preview 使用 Vite `preview()` API（读取原有配置和最终 dist），仅在本地中间件返回 server-mode health；其余 Function 路径返回 404，不转发到真实服务。该设置只存在于审核进程内，未写入产品/Vite 配置或产物；Lighthouse 因而只证明静态首页性能，不证明真实网关/后端延迟。

在仓库根目录启动等价审核进程：

```bash
node --input-type=module <<'NODE'
const { preview } = await import('vite');
const server = await preview({
  preview: { host: '127.0.0.1', port: 6396, strictPort: true },
  plugins: [{
    name: 'local-audit-health',
    configurePreviewServer(server) {
      server.middlewares.use('/functions/v1/app', (req, res) => {
        res.setHeader('Content-Type', 'application/json');
        if (req.url?.startsWith('/api/health')) {
          res.end(JSON.stringify({ ok: true, serverMode: true, serviceEnabled: true }));
        } else {
          res.statusCode = 404;
          res.end(JSON.stringify({ ok: false, code: 'LOCAL_AUDIT_NO_PAID_CALLS' }));
        }
      });
    },
  }],
});
server.printUrls();
NODE
```

## 风险与回退

1. 首次打开非首屏功能增加异步 chunk 往返；加载期间有 Suspense 状态，设置/帮助/原文成功加载后复用模块与组件状态。模块下载失败或旧页面访问已清理的旧 chunk 时可能需要刷新；后续发布应保留旧哈希资源或保证版本资源一致，本轮不发布。
2. 首包距 300 kB 门槛约 1 kB，后续新增首屏依赖容易反弹；以相同 gzip 方法和 production 实际请求持续检查，不只看文件名。
3. PDF 主包/worker 没有压缩优化；全功能 JS 合计略增。移动得分提升不代表真实移动设备或上传过程性能；桌面示例区 CLS 仍待后续改善。
4. 帮助 bootstrap 策略、调用预算和真实 provider 未调整；零付费的 mock 验证不能替代线上 DocMind/LLM、Origin/CORS、冷启动、真机浏览器验收。
5. 回退应作为一组撤销本轮 App/结果页/帮助系统/设置引用、analysis↔generation 拆分及 report 导入改动；保留或同步调整对应新增测试。先备份工作区，不能直接整仓 reset/clean；特别保留原有未跟踪交接文档。本轮未执行任何回退、git 暂存、提交、推送或发布操作。
